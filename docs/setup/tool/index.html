Set up once

The things that outlive any one project — your template, your saved locations, and a few machine settings. All of it lives in Settings, the sliders icon in the panel header.

You can skip this entirely and Toolbox will use its shipped template and sensible defaults. Come back when you want the folder scheme to be yours.

Settings edits live: there is no Apply. Close it with Done.

The template

A template is your folder scheme, saved as data. One template carries both halves of a project's conventions:

  • Project panel — where items go inside the After Effects project. Read by Organize, and by Import assets when you tell it to file what it imports.
  • Disk — where files go in the project directory. Read by Sort disk, Gather and Collect.

That is why it is the thing you hand to a colleague: one file, and their Toolbox files things the way yours does.

Choosing and saving

At the top of the template card:

  • In use — the dropdown of your saved templates plus the shipped one. A saved template with the same name as a shipped one replaces it, which is why editing "Default" is safe.
  • Read from project — fills every row it can infer from the open project, and shows how confident it is per row. Useful when a project already has a structure you like and you want Toolbox to keep to it.
  • Save as… — save the current rows under a new name.
  • Make default — what new jobs start with.

Two tools pick the template in their own sheet rather than sending you here: Organize (labelled Template) and Sort disk (labelled Directory structure). They read and write the same working template.

The Project panel tab

  • Where things go — one row per kind of item: top-level comps, precomps, comps nothing uses, video, raster, vector, audio, image sequences, solids, 3D, data, other footage. Type a folder path per row; use / for nesting. Leave a row blank to leave those items where they are. The ▲▼ arrows change the order, which matters if you number the folders.
  • Folder naming — number the folders (00_comps, 01_raster…), pad to two or three digits, join with underscore, dash or dot, apply to the top level only or every level. The order above is the order the numbers follow.
  • Your own rules — see below.
  • Special folders › Always create — folders Toolbox creates if missing but never files into and never empties. Reference material is yours to sort. This is also how a folder you keep empty on purpose survives the empty-folder sweep.

The Disk tab

  • Where files go — one row per media class: vector, raster, video, image sequences, audio, 3D, data, everything else. Paths are relative to the project directory — the one holding aep/. Blank means leave those files where they are.
  • A file arriving from a sub-directory — flatten it into the class directory (default), keep its last directory (raster/nested/bg.jpg), or keep every directory.
  • Your own rules — see below.
  • Special directories › Leave alone — never filed into and never emptied out. Default aep, out, render: outputs and inboxes, not destinations. Always create — created but never filled.

Your own rules

On both tabs. A rule sends anything whose name or extension matches somewhere specific, and rules are matched first, in the order listed, before the class rules. Match by name — contains _proxy, is exactly shot_010.mov, starts with PRE_, ends with _v2, wildcards *_proxy* — or by extension is exr. Matching ignores case.

Tip

Typing a * into a plain operator switches it to wildcards rather than matching the star literally. An extension typed as .exr or EXR is normalised. A rule with an empty pattern or an empty destination matches nothing.

Saved and recent locations

One store, shared by everything that asks for a directory: Render's output, Import's directory, Collect's destination, Relink's search directory, Gather's destination when the directory is unmanaged. A directory used once appears in every Go to picker where it makes sense, most recent first. In the picker: ★ marks a favourite so it stays at the top, ✎ renames it, … shows and copies the full path, × forgets it.

This machine

Below the template, and visually separate, because the template is shareable and these are not.

  • Searching — which directory reader Relink and Update use. Automatic tries the fast one and falls back if it cannot read; you can pin always the fast one or always through After Effects. The note under it explains: on a managed machine the fast reader cannot see a mounted server; After Effects can, so the search goes through it instead — around 45× slower, so only when needed. Ask again forgets what it learned.
  • Keep up with the project automatically — on by default. Re-reads the structure a moment after you import or delete, and never while something else is running.
  • Check on its own — the update cadence.

Also remembered per machine, but set where you use them: Resize's four standing choices, the background render resource tier, Import's table columns and sort, and every tool's last option choices.

What is worth deciding up front

  1. Which template — or accept the default. Every project tool reads it, including which folders survive the sweep.
  2. Whether the disk half matters to you. If you never let Toolbox touch files, the Disk tab and Sort disk are simply irrelevant.
  3. Update cadence.

Nothing else. Masters, Protected and Managed are per project — next page.
