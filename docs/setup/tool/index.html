Set up once

The things that outlive any one project — your template, your saved locations, and a few machine settings. All of it lives in Settings, the sliders icon in the panel header.

You can skip this entirely and Toolbox will use its shipped template and sensible defaults. Come back when you want the folder scheme to be yours.

Settings edits live: there is no Apply. Close it with Done.

The template

A template is your folder scheme, saved as data. One template carries both halves of a project's conventions:

  • Project panel — where items go inside the After Effects project. Read by Organize, and by Import assets when you tell it to file what it imports.
  • Disk — where files go in the project directory. Read by Sort disk, Gather and Collect.

That is why it is the thing you hand to a colleague: one file, and their Toolbox files things the way yours does.

Choosing and saving

In the Template band, above the structure:

  • In use — the dropdown of your saved templates plus the shipped one. A saved template with the same name as a shipped one replaces it, which is why editing "Default" is safe.
  • Read from project — fills every row it can infer from the open project, and shows how confident it is per row. Useful when a project already has a structure you like and you want Toolbox to keep to it.
  • Save as… — save the current rows under a new name.
  • Make default — what new jobs start with.

Two tools pick the template in their own sheet rather than sending you here: Organize (labelled Template) and Sort disk (labelled Directory structure). They read and write the same working template.

Structure

One band, two halves; the Project panel and Disk pills on its heading switch between them.

  • The table — one row per kind. Project panel: comps nothing uses, top-level comps, precomps, vector, raster, video, image sequences, audio, 3D, data, other footage, solids. Disk: the footage kinds only, with paths relative to the project directory — the one holding aep/. Type a folder path per row; use / for nesting. Leave a row blank to leave those items where they are. Now counts what the open project has of each kind (— with no project). The ▲▼ arrows change the Project panel order, which matters if you number the folders.
  • Your own rules — see below.
  • Folder naming (Project panel) — number the folders (00_comps, 01_raster…), pad to two or three digits, join with underscore, dash or dot, apply to the top level only or every level. The numbers follow the order of the table, and each row shows the name it will get.
  • Special folders — chips. Project panel: folders Toolbox creates if missing but never files into and never empties — reference material is yours to sort, and this is how a folder you keep empty on purpose survives the empty-folder sweep. Disk: Sub-directories says what happens to a file arriving from one — flatten (default), keep the last directory (raster/nested/bg.jpg) or keep every directory; Leave alone is never filed into and never emptied out, default aep, out, render — outputs and inboxes, not destinations; Always create is created but never filled.

Your own rules

In both halves, above Folder naming. A rule is a card: one or more tests, all of which must hold, and a send to folder. Cards are checked before the table's kinds, top to bottom — the first card that matches takes the item, and a card lower down that would have caught the same items reads rule 1 takes all of these. ▲▼ reorder; a second card is how you say "or".

The tests (+ and another test… adds one, each once per card):

  • name — contains · is exactly · starts with · ends with · wildcards (*_proxy*). Ignores case.
  • extension is — one or more, exr, dpx.
  • kind is — a row of the table, or any footage / any comp.
  • located under — a directory on disk, typed or Choose…. Footage only.
  • in project folder — that folder or below, numbering ignored.
  • changed in the last — N days or weeks, by the file's modification time.

Each card carries a live count — catches N items (click to list them), catches N items · K more go to rule J — or says why it is zero: matches nothing here, not finished, rule K takes all of these, needs masters declared, or — with no project open. A folder or age test reads the item as it is now, so a card using one is an inbox, not a fixed rule — it says re-checked every time you organize, and an item that has moved on is filed differently next run. That is the intent.

+ from selection starts a card from what the selected items share — extension, kind, a common directory; a selected folder becomes an in project folder test — and leaves the folder to you. + add a rule starts a blank one.

Tip

Typing a * into a plain name operator switches it to wildcards. In the Disk half send to must be inside the project directory, or the card reads not finished.

Saved and recent locations

One store, shared by everything that asks for a directory: Render's output, Import's directory, Collect's destination, Relink's search directory, Gather's destination when the directory is unmanaged. A directory used once appears in every Go to picker where it makes sense, most recent first. In the picker: ★ marks a favourite so it stays at the top, ✎ renames it, … shows and copies the full path, × forgets it.

This machine

Below the template, and visually separate, because the template is shareable and these are not.

  • Searching — which directory reader every disk walk uses: Relink, Update assets and Import's scan. Automatic tries the fast one and falls back if it cannot read; you can pin always the fast one or always through After Effects. The note under it explains: on a managed machine the fast reader cannot see a mounted server; After Effects can, so the search goes through it instead — around 45× slower, so only when needed. The line beneath says what was remembered; Ask again forgets it. A whole-tree Import scan asks each time regardless.
  • Keep up with the project automatically — on by default. Re-reads the structure a moment after you import or delete, and never while something else is running.

Check on its own — the update cadence — sits at the top of the sheet in the Toolbox band, beside the version and Check for updates.

Also remembered per machine, but set where you use them: Resize's four standing choices, the background render resource tier, Import's table columns and sort, and every tool's last option choices.

What is worth deciding up front

  1. Which template — or accept the default. Every project tool reads it, including which folders survive the sweep.
  2. Whether the disk half matters to you. If you never let Toolbox touch files, the Disk half and Sort disk are simply irrelevant.
  3. Update cadence.

Nothing else. Masters, Protected and Managed are per project — next page.
