Reference

The words the panel uses and what each one means, the limits worth knowing before you hit them, and where Toolbox keeps your files.

Vocabulary

Two words carry most of the weight, and they are not interchangeable anywhere in this manual: a folder is inside the After Effects project, a directory is on disk. The panel's own wording has not fully caught up — you will see "folder" on a few strings about things on disk.

TermWhat it meansWhere you meet it
FolderA folder inside the After Effects project.everywhere
DirectoryA directory on disk.everywhere
Project directoryThe directory everything on disk is measured from — the parent of aep/, or the .aep's own folder.the header identity row
ManagedToolbox may shape this directory. The default.the header Managed ▾ button
UnmanagedToolbox will not shape this directory — for a project living inside somebody else's job tree.the same button
Job directoryOn an Unmanaged project, the directory that bounds what counts as inside.the Managed/Unmanaged sheet
MastersThe comps you have declared the point of the project, tagged [MASTER] in the comp's Comment.the header strip
ProtectedItems — and whole folders, meaning everything under them — tagged [KEEP]. Never moved, renamed, removed or copied by any tool.the header strip
TemplateThe folder scheme as data: the Project panel half and the Disk half in one shareable file.Settings, and the Template / Directory structure pickers
Create-only folderA folder the template creates but never files into, whose contents are never touched, and which survives the empty-folder sweep while empty.Settings › Always create
TierThe kind of an item, for routing and for scoping a run — top-level comps, precomps, comps nothing uses, vector, raster, video, image sequences, audio, 3D, data, other footage, solids.Organize's What to organize, the Settings rows
SweepThe automatic removal of folders a run emptied. A full run sweeps the project; a partial run sweeps only what it emptied itself.Organize, Consolidate, Empty folders
StrayFootage on disk outside the project directory — or, when unmanaged, outside the job directory.Gather
RelocatedMore than 80% of the footage sits outside. Either the project was moved away from its footage or it was never meant to live beside it.the header nudge; Gather and Sort disk
Layer setThe items After Effects creates from one layered .ai or .psd — one asset spread over several items.Organize, Rename, Unused
DriftHow far the project sits from this job's own Organize settings. Hover only.the footer
BasketThe comps a render or a collect is for.Render, Collect
Version rootThe folder version numbers are counted from — the comp folder, above any date folder.Render
ReachHow far up from each footage file Update assets climbs before searching downward.Import
SchemeWhat a version number looks like: v001, _001, or either.Import

Two tools are known by two names each, because the tile is short and the sheet is explicit: the Sort disk tile opens a sheet titled Organize files on disk, and the Empty folders tile runs an operation labelled Remove empty folders. Protected and [KEEP] are likewise one thing — the strip is the control, the token is what you would type into a Comment by hand.

Limits

30,000 pixels. After Effects' own maximum comp dimension, and Toolbox meets it in two places with two different responses. Resize refuses outright — W×H is over After Effects' maximum of 30000×30000 — because a refused resize is recoverable and a truncated one silently is not. Comp settings accepts 1–30000 in its Width and Height fields and leaves an out-of-range entry alone rather than quietly clamping it to something you did not type.

Layer styles are not scaled by Resize, and not reported. A layer style's own lengths — a stroke width, a shadow distance — stay at their original values when a comp is scaled. Resize names what it changed and what it could not; layer styles are the known gap in that list, so check them by eye on anything that carries one.

Multi-output presets share one version number. An output module template that writes several outputs gets a single {version} for all of them, not one number each.

macOS only. There is no Windows version. Toolbox does not restrict which After Effects version it runs in.

The network. The update check is the only thing Toolbox uses the network for.

Where your files live

Everything Toolbox keeps for you is in ~/Library/Application Support/Toolbox/, and an install or an update never touches it.

PathWhat it holds
templates/*.jsonYour saved templates.
prefs.jsonEvery machine preference, every tool's last option choices, Collect's settings, the working template, and the per-job memory.
default.txtThe name of the template you marked default.
render-template-formats.jsonWhat each After Effects output-module template actually writes.

A saved template shadows a shipped one of the same name when both exist, which is why editing "Default" is safe — the shipped one is still there underneath. If you used the tool under its old name, Toolbox copies the contents of an AEOrganizer folder across once and says so in the status strip.
