Import assets

Browses a directory and shows you what is in it — sequences as one row each, with length, size and what the project already has — then imports what you tick.

Use it when

  • A delivery has arrived and you want to see what is in it before anything enters the project.
  • You want only the files that landed since yesterday, not the whole folder again.
  • A four-hundred-frame sequence needs to come in as one item, at the right frame rate.
  • You want what you import filed by your template on arrival instead of piling up in the project root.
  • A batch belongs in one folder you already made by hand.

What it does

Reads a directory you name, three levels down, and lists what it found: video, stills, audio, image sequences collapsed to one row each, and everything else as an extension chip. Every row carries its length, modified date, size, and whether the project already has it. You tick rows and press Import — and if you ask, what arrives is filed by the Project panel half of your template.

What it does not do: nothing on disk changes, so no file is copied, moved or renamed. It builds no thumbnails. And it reads nothing at all until you press Scan — a directory sitting in the field has not been touched.

Do it

  1. Press the Import tile. Nothing is read until you scan; the line at the top of the sheet says so, and the Import button at the top right stays grey until there is something ticked to import.
  2. Choose a directory, three ways into one store: Go to for somewhere you have been before, the path field to type or paste, or Browse…. The resting line says choose a directory · nothing is read until you scan.
  3. Press Scan. It counts as it goes — n directories · n files… — with no progress bar, because there is no total. Stop ends it.
  4. Narrow what you are looking at: the name box, Filters ▾, and the extension pills.
  5. Tick the rows you want. Set the sequence frame rate and Put them in.
  6. Press Import n items.

Scope. The scan is bounded by the directory you name and by three levels of depth — nothing above or beyond that is read. What is selected in the Project panel matters only for the destination: one selected folder becomes the third Put them in option, and it is targeted by id, so renaming that folder later cannot break the import.

What you'll see

Filter by name…Filters as you type. It deliberately does not count toward the Filters badge — it is text you are already looking at.

Notes it may raise, and what they mean:

  • n hidden by filters, with a clear link, or nothing hidden. A filter that empties the list says so.
  • n already in the project — importing again makes a second copy. — a warning, never a block. A second copy is legitimate.
  • nothing here is media — open it to pick anyway — the pill row on a directory of documents.
  • tick the files you want, then press Import, or n ticked, but hidden by the filters — clear them to import. The button is always drawn, and it says which zero it is.
  • Refusals under the path field, in red: no directory given · that is not a full path — it must start with / · the whole disk is not a place to scan · every user, or every mounted volume — pick one inside it · nothing is there · that is a file, not a directory. And one in amber that is a warning, not a refusal: that is an entire volume — scanning it will take a while.
  • In the Length column, … means queued and — means measured but unknown. Sorting by Length suspends the measuring so rows do not reshuffle under the cursor.

Undo

One ⌘Z, named Toolbox import. Nothing on disk changes either way.

Watch out

Watch out

Padding width is identity. f_9.png and f_10.png are two separate runs, not one run of two frames, because that is how After Effects itself reads them. If a sequence arrives split in two, that is why — check the frame numbering on disk.

Note

The scan stops three levels down. That bound is the feature: an unbounded browse of a job root has walked 1,764,624 files in this panel's history and stopped it dead. If what you want is deeper, scan from a directory nearer to it.

Note

What counts as a frame is decided conservatively. Containers — .mov, .mp4, .psd, .ai, .aep — are never frames, and a trailing _v03 is read as a version rather than a frame number. A run whose numbering is more than 95% gaps is treated as stock-library IDs and becomes ordinary stills.

Things you might not think to do

  • Take an inventory of a handoff folder without importing anything. The pill row is a content census — 62 png · 60 exr · 4 wav — and length, modified date and size are all readable from the table.
  • Import only what arrived since yesterday. Filters ▾ → Modified: Last 24 hours, then tick Hide already imported.
  • Import a batch straight into a folder you made by hand. Select the folder in the Project panel first; the third Put them in option carries its name.
  • Let the template file the arrivals. Put them in: Folder template routes each item by kind, the same way Organize would — so a fresh import needs no tidying afterwards.

Pairs with

Update assets, for footage the project already uses. Set up once is where the template that Folder template reads is edited. Organize files anything that came in some other way.
