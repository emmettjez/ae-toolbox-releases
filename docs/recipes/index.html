Things you might not think to do

Twelve jobs that are an afternoon by hand and a few presses here — each one links to the tool page that explains it properly.

Every one of these is something After Effects will let you do the slow way. The steps are short on purpose; the tool pages carry the options and the warnings.

Hand a job to a freelancer as one self-contained folder, instead of zipping the project directory and hoping.

  1. Declare your master comps in the header — Masters ▾ → + add selected. See Set up each project.
  2. Collect → Only these comps, tick Copy the files too and Tidy the collected project, choose a destination.
  3. Press Collect. The path is already on your clipboard.

Clean up after merging a template or a previous version of the job, instead of hunting for which of the two bg.movs is yours.

  1. Consolidate first — it links the imported items to files you already have and deletes the byte-identical copies.
  2. Organize with Leave imported .aeps off.
  3. Nothing else to press: the empty-folder sweep runs with it.

Doing these in the other order makes the copies unmatchable forever — once Organize has filed them by kind, nothing can tell the copy from the original.

Rescue a project that was moved away from its footage, instead of relinking one item at a time.

  1. Read the nudge in the header first. If this is one project among many in a larger job, switch it to Unmanaged and stop here — see Set up each project.
  2. Relink, choose the directory the media now lives in, press Search.
  3. Gather with copying them, to bring the strays inside the project.
  4. Sort disk to file what is now inside.

Deliver a 4K version of a 1080 build, instead of changing the comp size and re-laying every layer.

  1. Select the master comp.
  2. Resize → Presets: 2160 tall, or Factor 2.
  3. If it warns about a shared precomp, set Shared: Duplicate and re-read the preview.
  4. Read the warnings, press Resize n, then check anything it named.

Version up every render without touching a single filename.

  1. Render → Name, any rule containing {version}.
  2. Add your comps, choose the output module and the destination.
  3. Queue n or Render n in background. The next number is read from disk and from After Effects' own queue, so two renders in a row cannot collide.

Render overnight without tying up your After Effects.

  1. Render → add comps, pick the format, pick the output.
  2. Background → Resources: Balanced. Leave continue if footage is missing off, so it fails loudly rather than delivering a hole.
  3. Render n in background. Queue more; they chain by themselves.
  4. In the morning, press the strip's finish button to import them.

Bring a client's new plates into a project you have already built, instead of replacing footage item by item.

  1. Update assets → Version looks like: either, Look in: 1 dir. up.
  2. Scan, then read the cost preview and the refusal rows before anything happens.
  3. Update n files. Nothing on disk changes — only the references.

Import today's renders and have them filed by your template on arrival.

  1. Import assets → choose the render directory, Scan.
  2. Filters ▾ → Modified: Today, and tick Hide already imported.
  3. Put them in: Folder template, tick what you want, Import n.

Strip a project down to what one deliverable needs, in place, instead of building a new project around it.

  1. Declare the master.
  2. Reduce → Keep: declared masters. Read the Keep line before pressing — this one removes.
  3. Empty folders to clear what the removal left behind.

Audit how far a project has drifted from its own spec — and change nothing.

  1. Select your master comp, open Comp settings.
  2. Copy settings from › Master.
  3. Read the badge beside each field: that is how many comps do not match. Press Cancel. You have your answer and the project is untouched.

Make a genuinely independent variant of a build, instead of duplicating a comp and finding both versions share every precomp.

  1. Select the comp, open Duplicate.
  2. Leave Footage: share with the original unless you need a separate interpretation.
  3. Set Add this text to the end of every copy: _v2, and read the preview — it lists every comp the tree reached.

Protect an externally-managed renders folder from every tool, forever.

  1. Select the folder in the Project panel.
  2. Header → Protected ▾ → + add selected.
  3. Everything inside it, at any depth, is now walked around by Organize, Rename, Reduce, Unused, Consolidate, Duplicate, Gather, Sort disk and the empty-folder sweep. See Set up each project.

Take ownership of media shared with another project, so the other copy can be deleted.

  1. Relink, tick Also repoint footage that is not missing, and search the directory you want this project to own.
  2. Gather with Bring them in by: moving them.
  3. Read the confirmation carefully. Moving is the irreversible one, and the other project will lose the files.
